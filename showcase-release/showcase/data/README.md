# Showcase data

The SQLite database `lumen_showcase.sqlite3` is created on first start and is intentionally excluded from the ZIP. The runtime seeds 80 deterministic synthetic case records and 30 synthetic entity labels. The seed generator uses district-centre reference points with randomized offsets for a map demonstration.

All labels use `Demo Person` and `DEMO-FIR` identifiers. They are fictional. The dataset must not be mixed with real case information.
